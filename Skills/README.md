# Generalized skills

These are generalized skills and utility patterns you can point your agent at for
inspiration. **They are not installation-ready skills.** They describe reusable
workflows; the overview notes do not include configured integrations, credentials,
or schedules. Monthly Financial Reporting also has a separately linked code
package with reusable helpers that require adaptation.

Private names, paths, account details, records, and operating preferences have
been removed. Folder names group the references by workstream. These notes are
separate from the original installed skills and their private operating context.

## Point your agent here

> Read this README and the relevant reference. Use the workflow as inspiration
> for my environment. Identify required configuration, tools, and decisions;
> adapt it into a working skill rather than assuming these notes can be installed.
> Use fictional data for initial checks. Show the finished result before seeking
> any required approval to send, publish, schedule, or change external records.

Each reference describes its inputs, workflow, output, and adaptation needs.
Validate the adapted implementation in its actual environment before relying on it.
